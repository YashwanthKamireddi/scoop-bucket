# Skykeep for Scoop

[Skykeep](https://github.com/YashwanthKamireddi/Skykeep) brings your iCloud Notes, Reminders, Calendar, Contacts, Drive and Photos to Windows as desktop apps.

```powershell
scoop bucket add skykeep https://github.com/YashwanthKamireddi/scoop-bucket
scoop install skykeep/skykeep
```

Update with `scoop update skykeep`. Skykeep leaves its updates to Scoop when Scoop installed it.
